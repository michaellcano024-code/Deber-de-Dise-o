Ejemplo: Uso del elemento <div> y del atributo id

El elemento <div> permite agrupar y organizar diferentes elementos dentro de una página web.

¿Qué es <div>?

Es un contenedor que puede incluir textos, imágenes, enlaces, listas y otros elementos HTML.

¿Qué es el atributo id?

El atributo id identifica de manera única un elemento HTML. Permite aplicar estilos con CSS y trabajar con elementos mediante JavaScript.

Ejemplo:

En esta página utilizamos diferentes id como: contenedor, cabecera, menu, contenido y pie.

Conclusión

El elemento <div> ayuda a organizar la página, mientras que el atributo id permite identificar cada sección y aplicar diferentes estilos.
